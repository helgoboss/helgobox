=== Display status bar if help panel hidden

image::helgobox::generated/screenshots/elements/settings/display-tooltip-if-help-panel-hidden.png[Display status bar if help panel hidden]

If enabled and the help panel in the bottom right corner is not visible, a status bar will be shown instead.
