== Behavior

include::partial$generated/elements/settings/preferred-midi-editor.adoc[]

Auto:: When running inside of REAPER, the default is to use REAPER's MIDI editor.
When running outside of REAPER, for example on mobile devices, the default is to use the Helgobox MIDI editor.
