=== Track input

image::playtime::generated/screenshots/elements/track-panel/input.png[Track input, role="related thumb right", float=right]

Pick the hardware input of the associated track used for recording and input monitoring. This can be a MIDI or audio input.

If the recording origin of this column is set to **Track audio output**, this setting will affect the recording track.
