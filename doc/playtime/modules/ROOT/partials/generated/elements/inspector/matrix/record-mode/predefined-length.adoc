==== Predefined length

image::playtime::generated/screenshots/elements/inspector/matrix/record-mode/predefined-length.png[Predefined length, role="related thumb right", float=right]

Recording stops automatically after the specified length.

This is useful if you know in advance that you want to record, let's say, 2 bars only. Then you don't have to reach for the stop button manually.
