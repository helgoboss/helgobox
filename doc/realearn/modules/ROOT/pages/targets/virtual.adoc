= Target "Virtual"

This is exactly the counterpart of the possible xref:further-concepts/source.adoc#virtual-source[virtual sources] in the {term_main_compartment}.
Choosing a {term_virtual_target} here is like placing cables between a {term_real_control_element} and all corresponding main mappings that use this {term_virtual_control_element} as source.

== Learnable checkbox

If you disable this checkbox, this virtual source will not be learnable via {term_learn_source} in the main compartment.
This can be useful for rather unimportant xref:key-concepts.adoc#control-element-interaction[control element interactions] such as _Fader touch_ that would otherwise make it very hard to learn more important sources such as _Fader movement_.
