= Target "Project: Any on (solo/mute/...)"

This target is most useful in feedback direction.

Map it to some LED on your controller.
Depending on your target settings, the LED will light up, for example ...

* ... when at least one of the tracks in your project is mute
* ... when at least one MIDI editor is focused

If the control element is a button, pressing the button will e.g. unmute all tracks in your project.
