= Target "Playtime: Matrix action"

Invokes a {term_playtime_matrix}-related action.

== Action menu

The kind of action to be executed.

Stop::
Stops all clips in the matrix. See {term_playtime_column_cell_stop}. Supports real-time operation.

Undo::
When hit with an _on_ value, undoes the last matrix operation. See {term_helgobox_title_bar_undo}.

Redo::
When hit with an _on_ value, redoes the last matrix operation. See {term_helgobox_title_bar_redo}.

Build scene::
When hit with an _on_ value, builds a {term_playtime_scene} of all currently playing xref:playtime::key-concepts.adoc#clip[clips] in the first empty {term_playtime_row}.

Set record length mode::
Switches to a specific record-length mode. At the moment, only two possible modes exist: *Open end* and *Custom length* are supported. They correspond to the off and on state of {term_playtime_inspector_matrix_recording_length}.

Set custom record length in bars::
Sets the {term_playtime_inspector_matrix_recording_length} to the desired number of bars.

Enable/disable click::
When hit with an _on_ value, enables the {term_playtime_toolbar_metronome}, otherwise disables it.

Enable/disable MIDI auto-quantize::
When hit with an _on_ value, enables {term_playtime_inspector_matrix_recording_auto_quantize}, otherwise disables it.

Smart record::
When hit with an _on_ value, triggers the {term_playtime_toolbar_smart_record} function. If this leads to the stop of a {term_playtime_feature_tempo_detection}, the operation can be carried out in real-time.

Start or stop playback::
When hit with an _on_ value, this starts Playtime playback and plays all xref:playtime::further-concepts/slot.adoc#ignited-slot[ignited] slots. Otherwise, this stops Playtime playback. This basically resembles the {term_playtime_toolbar_start_stop_playback} button. This action supports real-time invocation.

Enable/disable silence mode::
When hit with an _on_ value, this stops Playtime playback. Otherwise, it starts playback _without_ playing xref:playtime::further-concepts/slot.adoc#ignited-slot[ignited] slots. This action supports real-time invocation.

Panic::
This abruptly stops all clips in the matrix. This resembles a double click on the {term_playtime_matrix_cell_stop} button. This action supports real-time invocation.

Enable/disable sequencer recording::
When hit with an _on_ value, this starts recording a new {term_playtime_matrix_sequence}, otherwise it stops recording.

Enable/disable sequencer playing::
When hit with an _on_ value, this starts playting the currently active {term_playtime_matrix_sequence}, otherwise it stops playing.

Tap tempo::
Invokes the tap-tempo function. This action supports real-time invocation. See {term_playtime_toolbar_tap_tempo}.
