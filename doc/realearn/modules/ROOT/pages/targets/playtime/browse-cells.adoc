= Target "Playtime: Browse cells"

Changes the currently {term_playtime_active_cell}.

Best used with xref:further-concepts/mapping.adoc#rotary-endless-encoder[encoders] or previous/next-style buttons.

== Scroll

Ensure visible::
Applies the minimal amount of scrolling to ensure that the cell is visible.

Force top-left::
Scrolls so that the activated cell appears always in the same spot: The top-left corner of the matrix.

== Axis

Sets the direction into which to browse.
