= Target "Playtime: Slot length"

Sets the {term_playtime_inspector_clip_start_pos} property of all clips in a {term_playtime_slot}.

- A control value of 0% sets the length to zero.
- A control value of 100% sets the length to the defined maximum value.

include::partial$targets/playtime/time-unit-menu.adoc[]

include::partial$targets/playtime/slot-menu.adoc[]

include::partial$targets/playtime/max-value-field.adoc[]

If you leave the field empty, the maximum length is dictated by the length of the clip as defined by the {term_playtime_clip_fixed_section}.

====
If {term_time_unit} is set to seconds, entering `8` restricts the length to 8 seconds.
====

include::partial$targets/playtime/step-size-field.adoc[]

If you leave the field empty, the target becomes continuous.

====
If {term_time_unit} is set to whole notes, entering 1/16 snaps length adjustments to a 16ths-note grid.
====
