= Target "Playtime: Row action"

== Action menu

The kind of action to be executed.

Most of the actions only execute when the target is hit with an _on_ value. In all other cases, it's specifically mentioned.

Play::
Acts like the {term_playtime_row_cell_play_scene} button. This action supports real-time invocation.

Build scene::
Acts like the {term_playtime_row_build_scene_from_currently_playing_clips} function.

Clear::
Acts like the {term_playtime_row_clear} function.

Copy or paste::
If the row contains clips, copies them to a matrix-internal clipboard. If the row is empty, attempts to paste clips from the matrix-internal clipboard into that row, replacing existing ones.

Activate::
Makes this row the {term_playtime_active_cell}.

== Row menu

The {term_playtime_row} on which to carry out this action. See {term_row_selector}.
