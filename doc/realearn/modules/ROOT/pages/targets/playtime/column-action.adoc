= Target "Playtime: Column action"

Invokes a {term_playtime_column}-related action.

== Action menu

The kind of action to be executed.

Stop::
Stops all slots in this column.

Arm/disarm::
When hit with an _on_ value, arms the associated {term_playtime_column_track}, otherwise disarms it.

Arm/disarm () exclusive::
When hit with an _on_ value, arms the associated {term_playtime_column_track} and disarms all other column tracks, otherwise disarms it.

Activate::
Makes this column the {term_playtime_active_cell} .

== Column menu

The {term_playtime_column} on which to carry out this action. See {term_column_selector}.
