= Target "Playtime: Slot pitch shift"

Sets the {term_playtime_inspector_clip_pitch_shift} property of all clips in a {term_playtime_slot}.

- A control value of 0% sets the pitch shift to the negative of the defined maximum value.
- A control value of 50% sets the pitch shift to zero.
- A control value of 100% sets the pitch shift to the defined maximum value.

The pitch-shift unit is semitones.
For absolute control, you can use xref:user-interface/mapping-panel/glue-section.adoc#round-target-value[ rounding] to snap to semitones.

TIP: You can use the {term_target_value_sequence} feature to snap to arbitrary scales.
For example, use `0, 2, 3, 5, 7, 8, 10` for minor scale.
Or `-11, -9, -8, -6, -5, -3, -2, 1, 3, 4, 6, 7, 9, 10` for diminished scale in both positive and negative direction.

Defines the maximum pitch shift adjustment in semitones.
You can also enter fractions, for example `1/2` or `0.5` for a quarter tone (50 cents).

If you leave the field empty, the maximum pitch shift will be 24 semitones (= 2 octaves).
