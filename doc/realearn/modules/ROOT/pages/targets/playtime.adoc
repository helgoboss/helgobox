= Playtime targets

The targets in this section are made for controlling xref:playtime::introduction.adoc[Playtime], the clip launcher contained in Helgobox.

[[column-selector]]
== Column selector

Column-related targets use a _column selector_ to define what {term_playtime_column} the target should be applied to.

The following kinds of column selectors are available:

Active::
The xref:playtime::further-concepts/matrix.adoc#active-cell[currently active] column.

At position::
Here you can refer to a fixed column by entering the column number, e.g. 2.

Dynamic::
Allows you to dynamically refer to a certain column.
See <<dynamic-selector-variables>>.

[[row-selector]]
== Row selector

Row-related targets use a _row selector_ to define what {term_playtime_row} the target should be applied to.

The following kinds of row selectors are available:

Active::
The xref:playtime::further-concepts/matrix.adoc#active-cell[currently active] row.

At position::
Here you can refer to a fixed column by entering the row number, e.g. 2.

Dynamic::
Allows you to dynamically refer to a certain row.
See <<dynamic-selector-variables>>.

[[slot-selector]]
== Slot selector

Slot-related targets use a _slot selector_ to define what {term_playtime_slot} the target should be applied to.

The following kinds of slot selectors are available:

Active::
The xref:playtime::further-concepts/matrix.adoc#active-cell[currently active] slot.

At coordinates::
Here you can refer to a fixed slot by entering the slot address, e.g. 2 and 4. The first number is the number of the {term_playtime_column}, the second one the number of the {term_playtime_row}.

Dynamic::
Allows you to dynamically refer to a certain slot.
There are two expressions, the first one should evaluate to the column index and the second one to the row index.
As always, expressions must evaluate to zero-based indexes!
See <<dynamic-selector-variables>>.

[[time-unit]]
== Time unit

Some timing-related targets offer the possibility to define a time unit in which entered values will be interpreted. This allows for great flexibility, especially because most targets allow entering simple expressions instead of just numbers.

The following time units are available:

Seconds::
A value of 1.0 stands for one second.
+
====
An expression of `1/4` means 0.25 seconds.
====

Whole notes::
A value of 1.0 stands for one whole notes (= 4 quarter notes), according to a specific tempo.
+
====
An expression of `1/4` means 1 quarter note. An expression of `6/4` means 1 whole note and 2 quarter notes.
====

Bars::
A value of 1.0 stands for one bar, according to a specific time signature.
+
====
An expression of `5` means 5 bars.
====

[[dynamic-selector-variables]]
== Dynamic selector variables

In addition to the general variables described in {term_dynamic_selector}, the dynamic selectors mentioned above grants access to the following variables:

[cols="m,1,3"]
|===
| Variable | Type | Description

| control_unit_column_index
| Integer >= 0
| Column index of the current top-left scroll position within the xref:playtime::further-concepts/matrix.adoc#control-unit[Playtime control unit] represented by this xref:key-concepts.adoc#unit[ReaLearn unit].

| control_unit_row_index
| Integer >= 0
| Row index of the current top-left scroll position within the xref:playtime::further-concepts/matrix.adoc#control-unit[Playtime control unit] represented by this xref:key-concepts.adoc#unit[ReaLearn unit].

| active_cell_column_index
| Integer >= 0
| Column index of the {term_playtime_active_cell}. If a row cell is selected, this resolves to `none`.

| active_cell_row_index
| Integer >= 0
| Row index of the {term_playtime_active_cell}. If a column cell is selected, this resolves to `none`.
|===
